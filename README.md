# devt

CLI quản lý môi trường dev bằng Docker (Traefik, HTTPS local, hosts sync).

## Cài đặt

macOS / Linux:

```bash
curl -fsSL https://raw.githubusercontent.com/son-lhs/devt-releases/main/scripts/install.sh | bash
```

Windows (PowerShell):

```powershell
irm https://raw.githubusercontent.com/son-lhs/devt-releases/main/scripts/install.ps1 | iex
```

Kiểm tra: `devt version`
